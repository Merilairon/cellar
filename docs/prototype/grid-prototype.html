Recipe Book — grid prototype

Pre-M2 spike. Static data, no server. Try the width switcher, units, scaling, list view, tapping a step, and Edit spans to move each step's start/end row with the buttons.

What this validates: real <table> with rowspan/colspan (screen-reader friendly), sticky ingredient column, spans that start at any row, top and bottom banners, split ingredient rows (sugar, half / sugar, remaining), unit and scale rendering, and a button-based span editor that is keyboard operable. Layout reacts to the frame width (container queries), so the width switcher is a faithful preview of phone, tablet and desktop.

Sample recipes are self-written; the reference table was used only as a layout study.
