## 3. Known mapper weaknesses

Reported by the T8 and gate work; the hard-set fixtures show the first and last two.

| Weakness | Evidence |
| --- | --- |
| Spelling variants between ingredient list and steps | `hard-spelling-variant-yoghurt` ends at 0.44 (medium) and is not exact. |
| Steps with no recognizable verb | `hard-steps-no-verbs` ends at 0.39 (low), structure partly wrong. |
| Ingredient names that are also verbs, and recipes with parallel preparations | Stated as known weaknesses by the task owner; not verified in source or fixtures here. The verb list guards only "brown" and "cream" against noun use (`step-verbs.ts`). |
| Ambiguous bare names ("sugar" with two sugars, "oil" with three) | Handled by refusing to guess: low confidence and an `ambiguous_name` warning. |

## 4. Repository hygiene

| Topic | Detail |
| --- | --- |
| Stale `/tmp/tmp.*` directories | `scripts/update-visual-baselines.sh` clones the repository into `mktemp -d` and runs Playwright in Docker, which leaves root-owned files (`data`, `test-results`, `next-env.d.ts`) in the clone. `rm -rf "$tmp"` on the host then fails for those files, so the directories remain (8 seen on this machine, removing them needs root). The script should clean up inside the container or `chown` before it exits. Not fixed. |
