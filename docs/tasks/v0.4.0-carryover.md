## 5. Changelog lines (T16)

- **Mapper behavior change (v0.3.1 m4, T14):** a first step such as "Make the dough" is no longer turned into a section heading unless it ends with a colon or the recipe has another heading. Recipes that relied on the old behavior now keep that line as a step and may map differently.
- **Cover URL base (v0.3.1 n4):** `normalizeRecipe` resolves a relative cover image URL against the final page URL after redirects (introduced in v0.3.1, never announced).
- **Sidecar:** entry URL limit 2048 characters (was 2000); it answers `busy` at capacity. Rebuild it when upgrading (`docs/deployment.md`).
- **New behavior:** `GET /api/recipes` rejects unknown and repeated query parameters with 400 `invalid_query` (the v0.3.2 list ignored them). `unit_pref` now changes recipe display. Imported tags are saved.
- **Dependencies:** `git diff v0.3.2 -- package.json` is empty (no dependency or script change). `src/lib/env.ts` and `.env.example` are unchanged since v0.3.2, so there are no new environment variables.
