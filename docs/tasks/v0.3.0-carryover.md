## 2. Decisions needed

| Topic | Detail |
| --- | --- |
| `source_url` always stored as https | The normalizer treats `http` and `https` as equal for duplicate detection, and the stored value is always the `https` form. This can be wrong for a site that only serves `http`, and the stored link may not open. Decide: store the user-entered scheme and normalize only for comparison. |

## 3. Known limitations and debt

| Topic | Detail |
| --- | --- |
| Raw HTML and `draft_json` never pruned (review M3, pruning part) | `KEEP_RAW_HTML` files are never deleted, and `import_job.draft_json` is kept indefinitely. Decide a retention rule (for example 30 days) for 04c or v1.0, together with backup. |
| Cover not displayed | Covers are stored and served by `GET /api/photos/:id` but the UI does not show them until 04c (v0.4.2). |
| Tags not persisted | Tags found on the page are shown read-only and live only in `draft_json` until 04a. |
| `prettier --check` fails on fixtures | The hand-written fixtures in `tests/fixtures/import/` are not prettier-formatted. Prettier is not part of CI, so this is not caught. Either ignore the folder or format it. |
| `npm audit` | Not fixed; see section 4. |
| Rate limiter in memory | As in v0.1: counters reset on restart. |

| | Baseline (before `c455f99`) | After (v0.3.0) |
