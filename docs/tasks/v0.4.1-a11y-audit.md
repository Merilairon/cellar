# v0.4.1 accessibility audit of the grid editor (T12)

Auditor role: testing-accessibility-auditor. Standard: WCAG 2.2 Level AA. Date: 2026-11-07. Branch `release/v0.4.1`.

## 1. Scope and method

| Item | Detail |
| --- | --- |
| Product | Grid editor on the recipe page (`src/components/recipe/grid-editor/`), Vanilla Cake sample (two sections, one portion split), owner account. |
| Automated | axe-core via `@axe-core/playwright`, tags `wcag2a wcag2aa wcag21a wcag21aa wcag22aa` (includes the `target-size` rule). `tests/e2e/grid-editor-a11y-states.spec.ts` (new) and `grid-editor-a11y.spec.ts`, Chromium (Playwright 1.64.1) only. |
| Scripted manual | Keyboard walks, focus checks, computed sizes and overflow measured in Playwright; contrast ratios of every `--ge-*` token pair computed with the WCAG 2.x luminance formula (section 3). |
| Viewports and themes | 375, 768, 1280 px, each in light and dark (`colorScheme`). Reflow at 320 px and 640 px (equivalent of 400 % and 200 % zoom on 1280 px). |
| Not a conformance claim | Only the editor, one sample recipe, one browser. WCAG conformance of the whole product is NOT DETERMINED. |

States covered by axe (every one at all three widths, light and dark, 6 runs): idle; selected step (inline panel at 768/1280, bottom sheet at 375); Adjust rows open (768/1280; the 375 sheet already holds the steppers); Row actions menu (768/1280) or row sheet (375); inline edit with parsed preview; undo toast; warnings with the Problems panel; network alert; 422 errors with the Problems panel; conflict panel; conflict confirm; leave confirm. Section delete confirm: 1280 dark only (it is a plain in-page confirm, the same markup at every width). Result: **0 violations in all of them** after fix A1.

## 5. Not tested (be explicit)

- **Screen readers: NOT TESTED.** No NVDA, JAWS, VoiceOver, TalkBack or Orca was run (no speech output is available here). Everything above about announcements is structural (roles, names, live region count, queue logic), not what a user hears. Needs a real pass: the rowspan table headers, the single polite region after Alt+Arrow, undo and save, `role="slider"` handles, the leave confirm and conflict panel focus moves.
- Voice control (Dragon, Voice Control), Windows High Contrast and forced-colors mode, screen magnifier software.
- Real touch devices, iOS Safari sheet scroll lock (O7, O12), Android back gesture. Touch was emulated only for the 44 px measurement.
- Browsers other than Chromium; real browser zoom (400 % was approximated by a 320 px viewport).
- Text spacing override (1.4.12), hover and focus content (1.4.13), the drag in progress itself (axe not run mid-drag; the drag tooltip is `pointer-events: none` and the drag has a keyboard twin).
- The Convert to grid screen, the read view and other pages (covered by their own specs).
- Focus when the undo toast overlaps a focused control (A6).
