Date: 2026-11-17. Tree: `release/v1.0` plus the uncommitted changes listed here. Audit: `docs/tasks/v1.0-a11y-audit.md` (its "Resolution" section maps every finding). Chromium 1.64.1 in `mcr.microsoft.com/playwright:v1.64.1-noble`. No dependency, no migration.
