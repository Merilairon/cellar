# v0.5.0 slice A: visual baseline review

Date 2026-11-15. Scope: 28 new and 20 changed Playwright baselines in `tests/e2e/__screenshots__/` (uncommitted working tree). Baselines were produced in the pinned image `mcr.microsoft.com/playwright:v1.64.1-noble` via `scripts/update-visual-baselines.sh` on a throwaway committed clone (341 passed). Every PNG was opened and judged by eye; the 20 changed files were also compared with their `HEAD` versions (pixel-diff bounding boxes plus block matching for shifted heights). Spec reference: `docs/tasks/v1.0-ux-spec.md` sections 1.3, 2, 3.2, 4.2.

Summary: no blocking defect. One minor visual defect (Copy link label wraps at 1280 in the dialog, 4 files). Two changed-baseline groups carry one extra, explainable change (notes print checkbox, 4 files).

## Open items

1. Minor: in `dialog-link-on-{light,dark}-1280` and `dialog-confirm-off-{light,dark}-1280` the "Copy link" button text wraps onto two lines next to the masked URL field. Not clipped, but untidy; baseline locks it in. Decide whether to fix the button (`whitespace-nowrap` or a wider button) before accepting these four.
2. Coverage gap: the 375 px notice, link-on and confirm-off sheets are cut at the 650 px (80dvh) sheet cap, so the bottom of the dialog (Public link switch in notice; Copy/New link in confirm-off) is not in those shots. This is a scrolling sheet, not a defect.
3. Not taken on purpose: `media-visual.spec.ts/cook-{checked,unchecked}-light-1280` regenerated with a 1 px row-height drift in the cook dialog, unrelated to this slice. They are NOT in the working tree and the old baselines are kept. Open item: unexplained sub-pixel drift.
4. The 375 recipe-page baselines get shorter (-52 px) because the actions row loses a line; the brief expected an extra line. Confirmed by diff; correct and intended.
5. The "Include notes when printing" checkbox in the Notes header (4 media-visual files) is a visible change beyond the actions row; confirm it is the intended T6 notes print option.
