Proof that this is the only cause: in a scratch clone I changed `.dockerignore` (`tests` to `tests/*` plus `!tests/helpers`); the image then built and everything in the Docker section below was done with that scratch change. The repo itself was not modified. Suggested real fix: the same `.dockerignore` change, or move the helper out of `tests/`. Re-gate needed after the fix (one build plus the paste smoke test is enough, the rest of the evidence below stands).
