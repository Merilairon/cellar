# Third-Party Notice

This project uses third-party agent definitions sourced from the **agency-agents** repository: https://github.com/msitarzewski/agency-agents. Each agent is a Markdown file under `.kilo/agents/` that defines a specialized AI agent's role, responsibilities, and behavior. The platform uses these definitions to route tasks to the appropriate specialist.

The agency-agents project is licensed under the MIT License. See https://github.com/msitarzewski/agency-agents/blob/main/LICENSE for the full license text.

The agents listed below are third-party (sourced from agency-agents, https://github.com/msitarzewski/agency-agents). The `project-assistant` agent is excluded from this notice because it is a project-created file, not a third-party definition.
